# Playbook: Resposta a Incidente (Genérico)

1. **Detecção** — validação do alerta, enriquecimento com CTI/OSINT.
2. **Triagem** — classificar severidade, impacto e escopo inicial.
3. **Contenção** — isolar ativos (EDR, firewall, NAC) e revogar credenciais afetadas.
4. **Erradicação** — remover artefatos, atualizar assinaturas/detections.
5. **Recuperação** — restaurar serviços, monitorar estabilidade.
6. **Lições aprendidas** — atualizar runbooks, detecções e métricas.

Checklist: manter registro no sistema de tickets, comunicação com stakeholders e preservar evidências forenses.

# 🖼️ Busca de Imagens

Ferramentas para buscar imagens por conteúdo visual.

## Busca Reversa de Imagem

### Google Images
- **URL:** https://images.google.com/
- **Descrição:** Motor de busca de imagens mais popular

### TinEye
- **URL:** https://tineye.com/
- **Descrição:** Busca reversa especializada em imagens

### Yandex Images
- **URL:** https://www.yandex.com/images
- **Descrição:** Motor de busca russo com bom reconhecimento de objetos

### Bing Images
- **URL:** https://www.bing.com/images
- **Descrição:** Busca de imagens da Microsoft

## Busca de Rosto

### FaceCheck.ID
- **URL:** https://facecheck.id/

### PimEyes
- **URL:** https://pimeyes.com/
- **Descrição:** Busca reversa especializada em rostos

### Search4Faces
- **URL:** https://search4faces.com/
- **Descrição:** Serviço de busca de pessoas por foto

### Betaface
- **URL:** https://www.betaface.com/
- **Descrição:** Reconhecimento facial online

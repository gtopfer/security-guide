# 🌐 Domínio e IP

Ferramentas para investigação de domínios, IPs e infraestrutura.

## WHOIS e DNS

### Domain Tools
- **URL:** http://whois.domaintools.com/
- **Descrição:** WHOIS lookup e dados históricos

### ICANN Lookup
- **URL:** https://lookup.icann.org/
- **Descrição:** Informações de registro de domínio

### SecurityTrails
- **URL:** https://securitytrails.com/
- **Descrição:** API para DNS atual e histórico, WHOIS

### ViewDNS.info
- **URL:** http://viewdns.info/
- **Descrição:** Ferramentas DNS múltiplas em um lugar

## DNS e Subdomínios

### DNSDumpster
- **URL:** https://dnsdumpster.com/

### Amass
- **GitHub:** https://github.com/owasp-amass/amass
- **Descrição:** Enumeration de subdomínios avançada

### Subfinder
- **Descrição:** Enumerator rápido de subdomínios

### Merklemap
- **URL:** https://www.merklemap.com/
- **Descrição:** Descoberta de subdomínios via Certificate Transparency

# 📸 Análise de Imagens

Ferramentas para análise de metadados e forensia de imagens.

## Extração de Metadados EXIF

### ExifTool
- **URL:** http://www.sno.phy.queensu.ca/~phil/exiftool
- **Descrição:** Ferramenta CLI poderosa para ler/escrever metadados

### EXIFEditor.io
- **URL:** https://exifeditor.io/
- **Descrição:** Editor online de EXIF em browser

### Metadata Viewer
- **URL:** https://kriztalz.sh/metadata-viewer/
- **Descrição:** Visualizador online de dados EXIF

### JIMPL
- **URL:** https://jimpl.com/
- **Descrição:** Visualizador de dados EXIF online

## Forensia de Imagem

### FotoForensics
- **URL:** http://www.fotoforensics.com/
- **Descrição:** Análise forense e detecção de manipulação

### Forensically
- **URL:** https://29a.ch/photo-forensics/
- **Descrição:** Suite de ferramentas de forensia de imagem

### JPEGsnoop
- **URL:** https://sourceforge.net/projects/jpegsnoop
- **Descrição:** Análise detalhada de JPEG

## Análise de Conteúdo

### DiffChecker (Image Diff)
- **URL:** https://www.diffchecker.com/image-diff/
- **Descrição:** Compara duas imagens visualmente

### ProfileImageIntel
- **URL:** https://profileimageintel.com/
- **Descrição:** Analisa fotos de perfil de redes sociais

## Geolocalização por Imagem

### SunCalc
- **URL:** https://www.suncalc.org/
- **Descrição:** Análise de sombras e iluminação para geolocalizar

### Pic2Map
- **URL:** https://www.pic2map.com/
- **Descrição:** Extrai coordenadas GPS de imagens

## Busca por Imagem Relacionada

### Reverse Image Search
- **Descrição:** Encontra uso de imagem em múltiplos websites

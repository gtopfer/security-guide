# Scripts Red Team

Organize ferramentas customizadas em subpastas:

- `automation/` — criação de infra, geração de usuários-alvo, envio programado de campanhas.
- `tradecraft/` — payloads, implant builders, wrappers para C2.
- `reporting/` — geradores de timelines e gráficos para relatórios.

> Sugestão: usar `poetry` ou `pipx` para distribuição e `pytest` para garantir estabilidade antes das campanhas.
